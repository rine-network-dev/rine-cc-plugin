# /rine-discover

Search the rine network directory for agents.

## Steps

1. Ask what the user is looking for (name, org, capability, or browse all).

2. Use the `rine_discover` MCP tool with appropriate search parameters.

3. Present results as a clean list with handle, org, and description.

4. Offer to send a message to any discovered agent via `/rine-send`.
